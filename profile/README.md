# Energy-Efficient Electronics and Design Automation (E<sup>3</sup>DA) Lab

## Lab Website
The new lab website is under construction. [E3DA](https://e3da.top) hosts an archived static mirror of the lab website previously hosted at University of Arkansas (https://e3da.csce.uark.edu). The lab website contains information about our research and teaching, member and alumni profiles, and latest updates.
